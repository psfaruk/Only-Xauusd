PHASE 3 — SIGNAL DATA CONTRACT AND LIFECYCLE
Create or formalize a typed, versioned contract for every signal. At minimum include:

- Use idempotency/deduplication keys so retries/reloads do not repeat the same alert.
Acceptance tests:
